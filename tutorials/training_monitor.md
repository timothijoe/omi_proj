# Actor / Learner 统一训练监控

监控入口只读既有会话，不启动 Actor、Learner、ROS 或机器人服务。
关闭网页或监控终端不会结束训练。训练命令仍按[异步 RL 教程](async_rl.md)运行。

## 启动与打开

在项目目录另开一个终端：

```bash
bash scripts/view_training_monitor.sh \
  --run local/rl_training/bc_demo_new_20261007_213643_rl_live_01
```

浏览器打开 **http://127.0.0.1:8768/**。端口占用时增加 `--port 8769`，并打开对应地址。
入口使用项目 `.venv`；实时状态和数据统计不依赖 ROS、Torch 或厂商 SDK。
逐帧审阅及输入图像需要已有的 NumPy、Pillow 环境。

已有会话可以立即浏览历史审计。实时心跳、仲裁和模型输入预览需由更新后的
`run_async_rl.sh` 进程产生：旧进程不会自动加载新代码，请在下一次按原流程重启训练后使用。
本功能没有修改策略加载间隔、训练预算、动作、入池规则或保护开关。

## 页面内容

- **链路总览**：已完成回合的原始 tick → 有效 transition → ready → imported；待导入条数和最长等待时间。
- **Actor 与仲裁**：回合阶段、剩余时间、RB、实际来源、门控、最终 SDK 命令、回执和两路话题。
- **Learner**：等待原因、Critic 更新、当前进程 Actor 更新、更新频率、训练/扫描耗时、loss 和 BC 漂移。
- **权重**：Learner 更新计数、最新发布确认、Actor 实际加载版本及下一次检查条件。
- **Replay 与质量**：三个分区占用、成功奖励条数、排除原因、磁盘空间。
- **传感器**：Actor 实际订阅的输入、回调频率估计、接收/Header 年龄、拒绝原因、历史完整度与最近完整模型输入。
- **回合审阅**：选择原始回合，逐周期、逐历史槽检查相机、触觉、命令 ID、配对状态及导入标记。
- **事件记录**：最近 40 条阶段变化、片段导入、权重发布和退出事件。

“暂停刷新”只冻结页面。曲线记录本页打开后观察到的最近 120 个不同更新值；
只有一个历史值时不绘制虚构趋势。事件与原始审计独立保存。

## 判断新鲜度

| 显示 | 含义 |
| --- | --- |
| 实时 | 后台心跳和主循环进度均在期限内，默认 5 秒 |
| 心跳过期 | 监控文件没有持续更新；不能据旧值判断进程仍在工作 |
| 主循环未推进 | 后台写者仍工作，但控制或训练循环长时间未报告进度；结合当前阶段检查是否长操作 |
| 已退出 / 异常退出 | 新进程退出时保存的终态 |
| 历史快照 | 只有旧版 `async_state.json` / `status.json`，没有心跳证据 |
| 未知 | 状态缺失或格式不支持 |

`--stale-seconds 10` 可改变监控提示期限；它不改变任何传感器或动作门控阈值。
网页与服务断连时保留上次显示内容并标记过期，不把旧图当成当前图像。

触觉保护仅订阅 `/omi/safety/tactile_guard`。该话题未出现或过期时显示未知/过期，
**不能从没有消息推断保护已关闭**。页面不会设置基线、复位锁定或改变开关。

## 数字的解释

`ready` 和 `imported` 按片段文件累计；Replay 数字是当前池占用，环形覆盖后不等于累计采集量。
在线人工干预同时进入在线与示范流，不能叠加为两份独立机器人经验。
本进程新导入、Actor 更新和 RL 更新计数在 Learner 重启后重新计数；
“RL 更新 / 新导入”只描述该进程内的计数比，不是训练预算或自动限速。

权重版本对应 Critic 更新计数；预热期间版本增加可不改变 Actor。
没有新版发布确认时显示未知，不从文件存在或 Learner 更新数猜测权重已传到机器人。
成功奖励是人工标记及合格末段的记录，不是独立自主策略成功率。

接收端回执表示接受命令，不能证明物理到达。传感器接收新鲜度、Header 年龄、
EEF 因果配对和实际运动分别判断，监控页面不放宽原校验。

## 可选：并入已运行的独立传感器看板

如果已按[实时 grid 看板教程](grid_live_review.md)启动看板，可传入它的实际输出目录：

```bash
bash scripts/view_training_monitor.sh \
  --run local/rl_training/bc_demo_new_20261007_213643_rl_live_01 \
  --sensor-status local/grid_live_review/live_user
```

页面读取该目录的 `status.json` 和 `dashboard.png`，显示独立看板的更新时间。
请替换为正在运行的目录；旧目录会显示过期快照。独立看板收到图像不代表 Actor 门控通过。

## 状态文件与退出

新版训练进程在会话内生成 `monitor/actor.json`、`monitor/learner.json` 和各自的
`*.events.jsonl`。监控写者约 2 Hz 原子替换快照；Actor 约 5 Hz 更新内存状态，网页约 1 Hz 拉取。
输入预览至多约 1 Hz 重绘，其余快照复用缓存并标明生成时间；触觉箭头隔点显示为 12×8。
图像生成与监控写盘在后台进行，内存只保留最新观测引用和有界事件队列；监控故障不作为动作执行条件。
这些文件是尽力而为的观察信息，不能替代原始 `periodic_episodes/`、训练片段、replay 和 checkpoint。

在监控终端按 `Ctrl+C` 仅停止监控服务。下一次训练重启仍自动写出遥测，无需更改既有训练命令。
本轮已验证软件回归、HTTP、真实已录会话读取与合成训练；浏览器视觉及真机并发开销仍待现场验收。
