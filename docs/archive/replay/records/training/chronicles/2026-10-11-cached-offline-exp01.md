## 结果

| 指标 | 原始BC | 更新1200次后 |
| --- | ---: | ---: |
| 留出人工动作归一化MSE | 0.2085827 | 0.1826416 |
| 留出全部窗口预测dx绝对值>0.98的比例 | 33.21% | 23.69% |
| 与原BC的动作MSE（全部留出窗口） | 0 | 0.0092498 |
| 与原BC的动作最大绝对差 | 0 | 0.3095692 |

人工动作MSE下降12.44%，说明这轮输出在该留出集上更接近记录的人类动作。
dx饱和比例下降不能单独解释为更好的插入行为，动作MSE也不等价于任务成功率。

需继续观察的结果：留出集记录动作的双Q均值范围 **-1.2905至-0.6787**，平均 **-0.9803**。
当前奖励非负，负Q提示价值估计尚不能认为已校准；不能仅凭critic loss变小判断学好了任务。

登记数据中的直接正奖励条数为：

| 分组 | 条数 | 正奖励条数 |
| --- | ---: | ---: |
| 初始人工示范 | 1387 | 5 |
| 本批训练人工动作 | 1955 | 0 |
| 本批训练策略动作 | 1088 | 6 |

这里按成功奖励实际落在哪条动作统计，不等于6个回合都是策略自主完成。
在完整Demo池3342条中均匀抽样，batch2预热1000步，直接抽到正奖励的期望次数约为
`1000×2×5/3342≈3.0`。这是理论期望，不是本轮实际命中次数；当前日志没有逐batch记录奖励命中数。
这是下一轮应记录和验证的具体方向，不据此擅自放大奖励或改变采样规则。
