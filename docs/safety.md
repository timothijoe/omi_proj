# 运行副作用与验证边界

本仓库已有真实采集和控制入口，不能把“开发中”或“查看器正常”理解成无动作风险。
每个入口的副作用见[CLI索引](interfaces/cli.md)，实际参数与使能以当前命令和保存配置为准。

- 看板、训练网页和只读诊断不发布机器人动作；实时传感器采集可能连接设备，录制会写盘。
- Actor／接收端与独立遥操作入口要遵守各自使能和输出所有权，不能用另一入口的默认配置替代。
- 接收端普通零指令停止新增目标，不证明物理即停；SDK提交、回执接受和反馈运动分别核对。
- 相机过期数据门控尚未补齐；图像mask、ROS节点存在或绿色显示均不构成数据新鲜证明。
- 删除经验不撤销已发生的模型更新，清理与恢复需要以原始记录、完整依赖和对应checkpoint核对。

长期原则见[决定索引](decisions/README.md)，当前技术缺口见[项目摘要](current.md)。
