# 安全与副作用边界

当前仿真 CLI 读取外部 MJCF，生成 `data/` 下的记录、模型和图片；它们不会连接控制器。`keyboard_teleop` 只控制 MuJoCo 模型，输入 `q` 或 `Ctrl+C` 结束。`sim_train` 会覆盖指定输出目录中的同名结果，因此运行前选独立目录。

`TianjiSdkArm` 是开发中的 SDK 边界，构造对象不会连接设备；`connect()` 会连接并读取状态，但不切换模式。运动还要求现场配置、`motion_authorized=True`、反馈帧递增、显式进入位置模式及受限关节目标。软件停止与异常处理已写入适配层，但**没有经过实机验收**。本仓库没有面向操作者的真机运动教程或默认运动命令。物理急停、工作空间、速度、负载、控制器版本和工具中心点须由现场确认。

对实机或外部服务的连接与运动应另行取得明确授权。仿真模型中的关节限位和成功阈值不是现场安全参数。事故、SDK 错误、帧停滞或状态不明时停止实验并由现场人员按设备流程处理；不要用训练脚本自动恢复运动。
