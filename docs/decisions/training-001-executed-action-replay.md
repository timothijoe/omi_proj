# 001：回放以最终执行动作为准

适用说明：executed_action是最终仲裁／限位后动作字段；真机主链的标签契约为accepted_command，不证明实际EEF位移或动作物理完成。当前解释见[数据接口](../interfaces/data-formats.md)。

**状态：有效。** 环境必须报告接管和限位后的 `executed_action`；SAC 回放记录此动作，策略原始请求仅作为审计字段。原因：在人工覆盖时，用策略原始动作配上人工造成的下一状态会污染 Q 学习。影响：所有后续设备/遥操作适配必须在同一动作语义下报告最终命令与来源，并在真实设备上区分“已下发”和“已执行反馈”。[当前实现](../modules/simulation.md)。
