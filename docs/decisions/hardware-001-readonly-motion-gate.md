# 001：默认只读与显式运动门

适用说明：构造／connect语义来自早期SDK适配器；实际ROS接收端的连接、模式和使能流程以[控制模块](../modules/control.md)及当前实现为准，不能直接套用适配器调用顺序。

**状态：有效。** SDK 适配器构造不连接，`connect()` 不切控制模式；运动必须由现场配置显式启用 `motion_authorized`，再检查反馈与位置模式。原因：训练和测试代码不能因创建适配器而驱动机器人。影响：硬件运行入口、现场教程和任何自动化都不能绕过此门；设备连接与运动的现场验收分开记录。[当前实现](../modules/control.md)。
