# Hardware 长期章程

硬件层只负责 SDK 会话、反馈、单位换算、模式进入、目标下发和停止。默认不运动；任何运动都要现场认可的配置、显式授权、状态验证和设备旁人员。训练与任务层不得直接调用 SDK。异常、帧停滞或状态不符应终止继续下发。详细契约见 [Tianji 适配器纪传体](../modules/control.md)。

模拟测试只能证明接口行为，不能证明控制器时序、物理限位、机械安全或急停有效性。

硬件输入设备也属于本领域；输入接收与机器人执行保持显式边界。设备或可视化测试不能当作机械臂执行验收，见 [SpacePilot 能力纪传体](../modules/teleoperation.md)。
