# 2026-10-01：SDK 边界与模拟测试

**当时目标：**为 Tianji A 臂建立不默认运动的 SDK 边界，先验证单位和状态契约。

**实际实现：**`TianjiConfig` 要求臂选择、关节限位、单步限制、速度/加速度比例等参数，`motion_authorized` 默认关闭。`TianjiSdkArm` 在 `connect()` 仅读取状态；验证帧、关节反馈和错误码；受授权后才可进入位置模式及发送角度目标；故障路径尝试软件停止与清理。

**当时证据：**假 SDK 契约测试及 MuJoCo SDK 替身测试进入总计 23 项自动测试通过的结果。没有真实控制器连接，也没有物理运动。

**当时限制：**SDK 版本、真实反馈时序、控制模式、工具、负载、物理急停与关节映射均未现场验收。

**后续影响：**设备与学习器保持明确接口，现场首先进行只读验证。
