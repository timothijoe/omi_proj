# 2026-10-03：共享内存结论边界与策略ROI传输方案

## 已发生的改动与结论

在[大图共享内存实验](2026-10-03-wrist-shm-trial.md)中，SDK、相机分辨率和图像内容不变，
通过独立Fast DDS组合配置使本机订阅由约10–12 Hz改善到30 Hz；65秒测试最大间隔72 ms。
旧默认入口保留；大图SHM实验是可选版本，不是默认全局替换。
本次解释明确：不能断言原链路完全未用共享内存，也没有逐项证明是哪一个参数独自修复问题。
只扩大UDP接收缓冲、UDP加同步发布均未解决；大图SHM组合有效。

其他机器录包即使不运行RViz，也存在ROS发布→rosbag订阅→写盘链路。
但这不证明旧bag异常原因与本机相同。源画面近乎静止、消息间断、回放卡顿以及整体时间滞后
是不同现象，需检查源帧内容、间隔和时间戳语义，不把当前优化当作旧包已被修复。

## 用户确认的下一步方向

1. 保留当前传输优化，增加独立策略ROI图像话题。
2. 裁剪再缩至128×128供策略使用，训练与推理统一处理契约。
3. RViz在显示端放大，不为大尺寸显示额外发送放大图。
4. 保留整图发布与录制能力，拟作为可选项；初期数据建议保留整图以便重新裁剪。
5. 本机裁剪只能减少本机之后的ROS/存储负载；设备侧裁剪发送未验证。

1920×1080原图、389×389仅裁剪、128×128裁剪缩放，在30 Hz三通道8位条件下，
理论像素负载分别约186.6、13.6、1.47 MB/s。不等同于实测网络带宽或成比例的延迟收益。
