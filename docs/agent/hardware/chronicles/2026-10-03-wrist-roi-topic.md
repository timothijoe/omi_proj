# 2026-10-03：腕部原图/ROI发布开关

按用户要求实现模式label和启动开关 `--image-mode full|roi`，两个启动脚本均支持，默认full。
full与roi分别发布image_raw/image_roi，不同尺寸不复用同一话题；ROI模式不同时发送整图。
ROI使用(.500,.704,.36)裁剪，nearest-rint-linspace缩至128×128 BGR8。
新纯函数与现有策略在横屏、竖屏、标准1080p和极小图上逐像素测试一致。
RViz根据模式生成运行配置并显示FULL/ROI标签；状态字段记录裁剪边界和处理版本。
标签不叠到策略像素里，不新增512显示图传输。

相关自动测试52通过4跳过，plan确认参数与topic。启动开关不是运行时热切换；
真机8秒订阅收到223帧（按首尾间隔29.68 Hz），128×128 BGR8，每帧49152字节；
状态为ROI且原图topic发布者为0。GUI截图确认ROI放大和对应面板标签。
模式切换重启camera/view，触觉保持运行。未修改原来的bag回放入口、未commit/push。
本机裁剪不会降低设备到本机的MJPG流量；既有策略/录包入口尚未自动使用新话题。
