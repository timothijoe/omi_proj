# SpacePilot 六自由度物体位姿

新增独立的[SpacePilot 末端增量发送工具](spacepilot-control.md)，支持平移/旋转独立倍率；本页原 GUI 继续仅用于物体演示，不会因新增发送工具自动连接机器人。

当前权威状态，更新于 2026-10-17。操作步骤见[教程](../../../../tutorials/spacepilot_pose.md)，接口见[输入与导出契约](../../interfaces/spacepilot.md)，形成过程见[编年记录](../chronicles/2026-10-17-spacepilot-pose.md)。

## 能力与边界

SpacePilot Pro 的六轴输入驱动本地长方体的 XYZ 位置和单位四元数姿态。Tk Canvas 正交投影显示物体、世界/物体坐标轴、网格、位置、RPY、六轴输入及按键状态。提供三种操控模式、单轴优先、世界/局部坐标切换、速度/死区/轴反转、暂停、复位、观察视角及 JSON 导出。

这是硬件输入验证和位姿演示工具，不发布 ROS、不导入厂商 SDK、不连接机器人控制器，也不写训练回放池；目前不能作为已经接入的机器人遥操作端。场景没有碰撞、重力或动力学约束。

## 当前代码与数据流

- 正式实现：`src/omi_hil_rl/hardware/spacepilot_pose.py`。
- 操作者入口：`bash scripts/spacepilot_pose.sh`。脚本定位仓库、设置 `PYTHONPATH`，默认用系统 `/usr/bin/python3`，可由 `OMI_SPACEPILOT_PYTHON` 覆盖。
- 不需要项目 RL 虚拟环境、NumPy、MuJoCo、浏览器或模型资产；需要 Tk 和系统 `libspnav.so.0`。
- USB → Linux 输入设备 → `spacenavd` → Unix socket / `libspnav` → `ctypes` 事件 → 校准映射 → 死区与轴反转 → 模式/单轴门控 → 速度积分 → Tk 显示/JSON。
- `--probe SECONDS` 只读取设备事件，不创建窗口。模块导入和 `--help` 不连接设备；实际启动 GUI 或 probe 才连接驱动。

## 当前坐标与操控

世界坐标为右手系：**前 +X、左 +Y、上 +Z**。驱动平移 `[x,y,z]` 映射为 `[z,-x,y]`；角速度 `[rx,ry,rz]` 映射为 `[rz,-rx,ry]`，包含用户反馈后的 roll 输入反转。这是本机手感映射，不是已标定的机器人 Base/Tool 变换。

默认仅平移，姿态锁定；仅旋转时位置锁定；六轴模式允许同时变化。SpacePilot 实体 1/2/3 的 libspnav ID 为 12/13/14，依次切换以上模式；只在按下时执行，每个事件独立派发。键盘 1/2/3 需要窗口焦点；设备按键经 socket 接收，不依赖键盘焦点。

单轴优先先屏蔽当前模式禁用的轴，再选择最大力度的一轴；新轴力度超过当前轴 1.35 倍才切换，回零解除选择。默认世界坐标积分；局部坐标模式将平移旋转到世界，并右乘角速度增量四元数。欧拉角只用于显示和导出，在 pitch 接近 ±90° 时存在通常的显示奇异性。

默认每轴最大平移速度 0.35 m/s、旋转速度 75°/s、死区 18。输入按参考量程 350 缩放并限幅，多个轴同时满幅时向量模长可超过单轴速度。超过 150 ms 无运动更新则清零；重连间隔 2 秒。这些机制只约束演示物体，不代表机器人停止保护。

## 资源、输出与迁移

设备为 `046d:c629` / `3Dconnexion SpacePilot PRO`。本机 Ubuntu 24.04 系统包：`spacenavd 1.2-1`、`libspnav0 1.1-2`、`python3-tk 3.12.3-0ubuntu1`，驱动 active/enabled。

导出对话框默认目录为 `local/spacepilot/`，可用 `--output-dir` 修改；用户可以在对话框另选位置。默认目录继承现有 `.gitignore` 的 `local/` 规则。迁移前文件和 SHA-256 清单保留在 `local/spacepilot/migration_20261017/`，本机后台窗口日志为 `local/spacepilot/viewer.log`。资源元数据见[清单](../../../../manifests/resources.yaml)。

工作区旧 `spacepilot_demo/run.sh`、`pose_demo.py` 仅作兼容转发；桌面应用入口已指向项目脚本。项目运行不依赖该旧目录，后续修改只维护项目源码。未引入大模型或 SDK 文件。

## 验证与限制

- 迁移前：实际 USB 枚举、驱动安装、六轴事件接收及 GUI 物体运动已经观察；用户逐次提出并确认使用方向，最终要求前 +X、上 +Z，并反馈 roll 反向。
- 项目内：脚本语法、`--help`、导入和 6 项专项自动测试通过。测试覆盖方向、模式锁定、单轴滞回、四元数/局部坐标、死区、短按事件批处理及过期输入清零。
- 项目内 2 秒只读探针识别到 SpacePilot PRO，连接成功；该次运动/按键计数均为 0，不把它记为运动验收。
- 项目 GUI 截图检查通过，显示累计 2244 条运动事件和变化后的 XYZ/RPY；真实实体 3 上报 ID 14，程序日志与界面均确认切入六轴模式。Tk 实例及 JSON 导出 smoke test 通过，输出目录、坐标顺序、单位四元数和元数据已核对。
- 实体 1/2/3 映射与事件分发通过模拟测试；本轮实体 3 已有真实事件证据，实体 1/2 尚无项目版本逐键人工验收记录。最终 roll 手感仍需用户实际操作确认；没有机器人运动验收。
- 不含 LCD 屏幕应用、按钮 4 及其他键的动作绑定、配置持久化、轨迹录制或长时间稳定性验收；参数在重启后恢复默认。
