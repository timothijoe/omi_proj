## 第一轮：单帧CNN，2000步

每个时刻使用最新因果观测：外部RGB、腕部ROI、双指触觉、7关节与7维EEF位姿。
输出未来约100ms的6D位姿变化代理标签；不是已确认的专家控制指令，无夹爪输出。
网络没有历史；Adam lr0.001、batch32、seed7、CPU，训练2000步。

| 数据/方法 | 平移分量RMSE(mm) | 旋转分量RMSE(rad) |
|---|---:|---:|
| 训练，初始化 | 0.882 | 0.002989 |
| 训练，最终 | 0.383 | 0.001210 |
| 验证，最终 | 1.037 | 0.004172 |
| 验证，零动作 | 0.927 | 0.003428 |
| 验证，训练集均值动作 | 0.896 | 0.003432 |

结论：拟合训练数据，但验证未超过两种基线，存在过拟合迹象；不能据此断言完全没有泛化能力。
相邻帧相关不能单独解释留出包表现差。单帧观测可能无法区分继续推进、持续受阻及退回调整。
本轮没有逐步验证曲线，不能从最终指标推断最佳训练步数。
模型与图：`local/eef_bc/oct3_formal_v3_run1/`。
完整已验证过程见[第一轮编年](../chronicles/2026-10-03-formal-training-run1.md)。

## 第二轮：最近1秒历史＋GRU

用户明确要求实现并重新训练。保持原8/2包划分、标签、归一化规则、优化器和2000步预算。

- 10Hz下取10个固定时刻t−0.9s至t，首末跨度0.9s，属于最近1秒的离散观测。
- 从原v3保留样本构建索引，缺失位置为-1，不紧凑拼接，不跨episode。
- 原v3中已因标签或输入无效而剔除的时刻，不重新引入作为历史；显式标缺失。
- 当前观测总存在；不足10帧的起始段保留，历史mask明确标记。
- 每帧共享CNN编码（两个视觉视角权重独立），投影128维；GRUCell隐藏128维。
- GRU接收相对时间位置；缺失历史跳过编码与隐藏状态更新。
- 每个窗口隐藏状态从零开始，不在窗口间维持全程记忆。
- 腕部optional训练dropout0.2；输入历史含视觉、触觉、状态和相机mask，不含未来标签或包编号。
- 每100步记录完整训练/验证指标；最终模型last.pt与最小验证归一化MSE模型best.pt分别保存。
- 使用验证集选best会产生选择偏差，不能当作独立测试成绩。

入口：`python -m omi_hil_rl.training.eef_bc_history`。
产物：`local/eef_history/oct03_run1/`（独立于正在归档的旧eef_bc目录）。
训练已完成，22项相关测试通过、1项跳过；历史索引逐元素验证无未来或跨包引用。


## 第二轮结果与当前判断

| 验证方法 | 平移分量RMSE(mm) | 旋转分量RMSE(rad) |
|---|---:|---:|
| 单帧，2000步 | 1.037 | 0.004172 |
| 历史GRU，2000步 | 1.011 | 0.004215 |
| 历史GRU，最优100步 | 0.907 | 0.003405 |
| 零动作 | 0.927 | 0.003428 |
| 训练集均值动作 | 0.896 | 0.003432 |
| 同一100步模型，屏蔽历史 | 0.880 | 0.003335 |

最终训练集0.230mm/0.000762rad；验证最佳100步，后续训练误差持续下降而验证恶化。
应先比较两轮同为2000步的结果：平移略改善、旋转略差。100步best不能与旧2000步直接比较后声称历史有效。
历史模型只略优于零动作，且屏蔽历史更好，本轮没有证明学到“受阻后退”。
模型结构容量也改变了；推理时屏蔽历史不是同结构重新训练的严格消融。
严格近静止阈值（平移<0.1mm且旋转<0.001rad）仅6/390个验证样本，
不能用“大多数样本完全静止”解释基线成绩。按基座−X粗分的95个样本仍差于零动作，
但−X标签不能直接等同于已标注退回阶段。

真实历史窗口：训练1063完整/72部分，验证372完整/18部分。模型重载预测完全一致。
完整过程、条件和局限见[历史GRU编年](../chronicles/2026-10-03-history-gru-training.md)。
曲线：`local/eef_history/oct03_run1/learning_curves.png`；完整指标：同目录`report.json`与`comparison.json`。
当前优先方向是核查/标注受阻和退回片段、检查标签对齐，再做同结构不同历史长度的受控比较。


## 第三轮：用户说明bag_002包含反复尝试，调整验证划分

当前有效划分：bag_002移到训练，bag_004替代其验证位置，保留bag_008。
训练1283样本、验证242样本；单帧和历史模型均从头训练2000步，其他参数不变。
bag_002可能包含恢复示教，保留而非删除；不从“不顺利”推断最终失败。

| 验证方法 | 平移分量RMSE(mm) | 旋转分量RMSE(rad) |
|---|---:|---:|
| 单帧，2000步 | 1.076 | 0.003819 |
| 历史GRU，2000步 | 0.967 | 0.003828 |
| 历史GRU，最优200步 | 0.846 | 0.003381 |
| 零动作 | 1.009 | 0.003375 |
| 训练集均值动作 | 0.943 | 0.003359 |
| 同一最优模型，推理屏蔽历史 | 0.924 | 0.003328 |

当前最佳历史模型为200步。平移较零动作改善约16%，旋转仍与基线接近且略差；
推理屏蔽历史使平移变差、旋转略好，历史收益是局部证据。
2000步仍过拟合；不能将选best后的成绩与旧划分分数直接比较。
验证集不包含bag_002，尚未确认足够恢复片段，不能证明学会受阻退回。
