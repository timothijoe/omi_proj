# oct_03 模仿学习实验与设计总结

更新依据：当前已完成的录包检查、单帧训练、历史GRU训练及验证集调整。
本页概括当前方案；各轮详细过程见[oct_03训练日志](oct_03-training-log.md)。

## 当前结论

已完成离线数据转换和训练，当前保留的最佳历史模型为新划分下的第200步检查点。
它在验证集上的平移增量预测优于零动作与均值动作基线，旋转误差与基线接近、略高。
继续训练到2000步，训练集误差大幅下降，验证集表现却退化，存在过拟合迹象。
目前不能证明模型具备受阻后退、恢复操作或真机闭环完成任务的能力。

## 2. 输入及时间处理

基础数据版本为 `bag-eef-bc-v3-grid-receive`，与早期v1/v2检查点不混用。

| 每个观测时刻的输入 | shape | 处理 |
|---|---|---|
| 外部RGB | 3×128×128，uint8 | 沿用既有ROI与resize |
| 腕部RGB | 3×128×128，uint8 | 录包已是ROI，仅BGR转RGB，不二次裁剪 |
| 相机mask | 2，float32 | 外部/腕部可用标记；本批保留样本均为[1,1] |
| 双指触觉 | 10×16×24，float32 | 每指deformation_xy、shear_xy、depth；已池化，不重复缩小 |
| 状态 | 14，float32 | 左臂7关节＋EEF xyz/xyzw |

两指wrench话题均没有消息，因此排除原先12维力/力矩输入，不以零值冒充测量。
训练归一化统计只使用训练集；图像转float并除以255。

每个参考时刻分别取已接收的最新有效观测，各传感器并非严格同时采样。
触觉header通常比录包接收时间快约28–32ms，腕部约20–24ms，跨设备时钟未校准。
因此统一使用**录包接收时间**对齐，并另外保留原设备header；不猜测或自动校正偏移。
接收层面的因果关系不等同于曝光/接触时间严格同步。

入口拒绝接收−header大于250ms的普通消息、大于50ms的EEF，或header超前接收超过100ms的消息。
在参考点选帧时，EEF最长年龄50ms，其他输入250ms。
4条明显过期外部图像及其他入口异常共42条源消息已剔除；源消息剔除数与无效参考点数是两种统计。
bag_009有约234ms原始EEF间断，过滤后有效标签不跨超过50ms的EEF间断。

## 3. 动作标签与基线

输出六维末端增量 `[dx,dy,dz,rx,ry,rz]`：平移为米，旋转为基座系旋转向量弧度。
标签来自参考点约100ms后的录制EEF变化：

```text
dp = p_future - p_current
dr = Log(R_future × R_currentᵀ)
```

未来EEF按接收时间选择，落在参考点后100–120ms；锚点为当前最新因果EEF。
它是未来状态变化的代理标签，不是已确认执行的专家控制命令；未训练夹爪维度。
TCP与真实控制基座对应未验收，本模型不直接接真机控制。

零动作基线对每个样本输出六个0，含义是预测末端位置和姿态不变化，不是回到原点。
它的分量RMSE为 `sqrt(mean(标签²))`。均值动作基线固定输出训练标签的六维均值。
它们用于检验是否优于简单预测，不代表不动就能完成任务。

平移/旋转RMSE分别汇总各自三个分量；不是位置欧氏距离、整段累计轨迹或闭环终点误差。
归一化MSE按训练集动作标准差缩放后，对六维误差平方取均值。

## 4. 从单帧到1秒历史

单帧模型只看到当前观测，可能无法区分刚接触、持续受阻、需要退回等状态。
加入历史的设计动机是观察接触变化、运动方向及持续性，不是预先认定记忆一定有效。

当前历史模型：

1. 10Hz下取10个固定时刻：`t−0.9s … t`，覆盖最近1秒内的离散观测，首末跨度0.9秒。
2. 每个时刻包含两路视觉、触觉、状态及相机mask；不输入包编号、动作标签或未来帧。
3. 从原v3保留观测构建索引；缺失时刻为-1，不压缩时间、不跨包拼接。起始段历史不足仍保留。
4. 每帧共享同一组编码器；外部与腕部视觉编码器相互独立。特征融合后投影至128维。
5. 128维GRUCell结合相对时间位置更新；缺失时刻跳过编码与GRU更新。
6. 每个窗口的隐藏状态从零开始，没有跨窗口的长期持续记忆。
7. 腕部训练dropout为0.2，评估时关闭；全模型195430参数。

新划分中，训练1211个样本历史完整、72个部分历史；验证224个完整、18个部分历史。
真实索引检查未发现未来或跨包引用。

## 5. 训练条件与结果

两模型使用同一新划分；Adam lr0.001、batch32、seed7、CPU，均训练2000步。
历史模型每100步评估完整训练集与验证集，评估关闭dropout。
`last.pt`保存最终2000步；`best.pt`按验证归一化MSE选择，本轮为200步。

### 历史模型：训练集下降幅度

| 指标 | 初始化 | 第200步 | 相对初始化降幅 | 第2000步 | 相对初始化降幅 |
|---|---:|---:|---:|---:|---:|
| 平移RMSE(mm) | 0.876 | 0.710 | 18.9% | 0.241 | 72.5% |
| 旋转RMSE(rad) | 0.003063 | 0.002591 | 15.4% | 0.000796 | 74.0% |
| 归一化MSE | 0.8454 | 0.5831 | 31.0% | 0.0601 | 92.9% |

这些是在完整训练集上评估的数值，不是随机minibatch loss。

### 新划分：验证集对照

| 方法 | 平移RMSE(mm) | 旋转RMSE(rad) |
|---|---:|---:|
| 单帧，2000步 | 1.076 | 0.003819 |
| 历史GRU，2000步 | 0.967 | 0.003828 |
| 历史GRU，最佳200步 | 0.846 | 0.003381 |
| 零动作 | 1.009 | 0.003375 |
| 训练集均值动作 | 0.943 | 0.003359 |
| 同一200步模型，推理时屏蔽历史 | 0.924 | 0.003328 |

200步模型的验证归一化MSE为0.8923；2000步为1.1632。
当前最佳模型平移较零动作低约16%，旋转基本持平、略差。
屏蔽历史使平移变差而旋转略好，是历史帮助平移的局部证据；推理消融不等于同结构重新训练对照。

## 6. 当前能说明什么

- 模型能拟合训练数据，200步后继续拟合未转化为更好的验证结果，表现出过拟合。
- 相邻帧相关只说明有效独立样本有限，不能单独解释训练与验证差距。
- 更换验证包后平移有改善，但新旧划分不同，不能把变化全部归因于历史或bag_002。
- 单帧与GRU模型结构容量也不同；缺少同结构、不同历史长度的严格对照。
- 验证集参与选择最佳检查点，不是独立测试成绩；单个seed也没有提供统计稳定性证据。
- 当前验证未确认包含足够反复尝试片段，无法证明学会受阻退回。
- 接收时间同步、未来状态代理标签、无wrench/夹爪及任务阶段未标注等限制仍存在。

建议后续先核查并标注受阻、后退、再次尝试的时间段及标签对齐，再比较历史长度、早停和模型配置。
这是后续讨论方向，本次总结没有启动新训练。
