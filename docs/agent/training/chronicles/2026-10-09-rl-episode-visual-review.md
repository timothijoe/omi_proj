# 2026-10-09：真机 RL 原始回合逐帧查看

用户希望逐回合可视化真实帧，以人工复查相机、触觉和动作记录。本次新增只读
`scripts/view_rl_episodes.sh` 与 `omi_hil_rl.hil.periodic_review`。入口只监听本机
`127.0.0.1`，按请求读取一个原始周期 NPZ；不会连接 ROS、发布动作或重写训练文件。

页面提供回合和周期选择、左右键及顺序播放、十个历史槽位选择。画面展示两路相机
的全部十帧、所选帧放大、A/B deformation/shear 向量和 depth；文本展示历史/相机
掩码、EEF 位置、动作来源、gate、命令、配对状态、训练片段及 Learner 导入标记。
没有观测的周期显示原始元数据而不伪造图像。`staging.json` 单独列为未完成回合；
训练片段位置从 `ready.json` 的源周期和计数计算，导入另查 `imported.json`。

对 `bc_demo_new_20261007_213643_rl_live_01` 的只读验证：目录索引识别 11 个周期目录，
其中 10 个有完整审计、1 个中断暂存；10 个完整回合共有 1059 条可训练 transition。
两次浏览器端 HTTP 请求分别验证无图像的早期周期和有图像、已入训练片段的周期；
另用真实第 50 周期渲染 PNG，人工查看两路相机、触觉和十帧选择布局。
这不是逐张人工验收全部 1959 个周期。两个完整回合各为 0 条可训练数据，
766 条周期因 EEF 因果条件不满足而排除；查看器不会改变这些判断。
