# 2026-10-02：磁盘 HIL 经验池与后台预取

## 目标与实现

针对视觉经验长期存放在 RAM 中的容量问题，新增 `DiskHILReplayBuffer`：memmap 数组、固定容量 ring、在线/示范掩码、批次预取、读写锁、writer 文件锁、检查点与重开。训练 CLI 增加后端、容量、目录和预取开关，默认内存后端保持原行为。策略快照可以独立加载，磁盘数组不 pickle。增加 RGB 图像吞吐基准入口及 [操作教程](../../../../tutorials/disk_replay.md)。当前完整机制见 [纪传体](../evolution/disk-replay.md)。

## 验证证据

- 全部自动测试 40 passed；磁盘测试覆盖内存池对照、图像一致性、双流、覆盖、超时、并发预取、重开、SAC+BC 更新、策略加载与异常退出拒绝恢复。
- 本机 A 臂 200 步，容量 64，101 次教师接管，150 次 SAC、150 次 BC 更新，保留 64 条（其中示范流 12 条）。短跑评估 0/2，不声称策略收敛。保存后独立评估与 200 条录制校验完成。
- 三路 RGB 基准容量 512、1024 次写入、100 个 batch 64；数组 151,094,272 字节，缓存采样约 29.7 batch/s，p50 33.6 ms、p95 41.0 ms，checkpoint 0.228 s。峰值 RSS 约 462 MB，包含整个进程。结果为缓存命中测试，不代表超内存数据集的 SSD 随机读取性能。
- 验证产物位于忽略的 `data/disk_replay_validation/`；文档本地链接、CLI help 和 `git diff --check` 已核查。

## 当时限制与后续

本版为单 writer、单采样调用线程，写入同步拷贝到 mmap、由 OS 回写，无独立异步写队列；当前/下一图像分存，无相邻帧去重或压缩。异常退出后 dirty manifest 拒绝恢复，未实现日志修复。没有完整 CLI 续训、超内存冷盘基准、多小时持续采集或真机验证。保留已有未提交修改，没有 commit 或 push。
