## 重训条件

历史为10Hz的10个固定时刻，最近1秒内t−0.9s至t，缺失位置mask，归一化仅训练集。
两模型采用完全相同的新划分，归一化统计逐项一致。

## 验证结果

| 验证方法 | 平移分量RMSE(mm) | 旋转分量RMSE(rad) |
|---|---:|---:|
| 单帧，2000步 | 1.076 | 0.003819 |
| 历史GRU，2000步 | 0.967 | 0.003828 |
| 历史GRU，最优200步 | 0.846 | 0.003381 |
| 零动作 | 1.009 | 0.003375 |
| 训练集均值动作 | 0.943 | 0.003359 |
| 同一最优模型，推理屏蔽历史 | 0.924 | 0.003328 |

最佳历史模型在第200步，平移比零动作约低16%，比训练集均值动作约低10%；旋转没有优于这两种基线。
对同一模型屏蔽历史后，平移变差、旋转略好，说明本轮历史对平移预测有帮助的迹象，不能概括成所有动作都改善。
这是推理时消融而非同结构重新训练对照，而且best使用验证集选择；不能当作独立泛化或因果结论。
同为2000步时，历史模型平移优于单帧，旋转略差；继续训练仍出现过拟合。

分包最佳模型：bag_004为0.901mm/0.003305rad；bag_008为0.796mm/0.003446rad。
以标签粗分：近静止6、基座+X148、基座−X42、其他46；这些不是标注过的恢复阶段。
新验证集没有被确认包含足够反复尝试过程，因此不能据此证明学会了bag_002的恢复策略。
