# 传感器完整性与物理解释验收要求

状态：持续待验收要求，非已完成能力声明。当前实现见 [传感器模块](../modules/sensors.md)。本页提取仍有效的验收目标，不强制所有策略启用全部字段。

1. 为每份数据明确raw/infer/deformation/shear/depth/wrench的来源、shape、dtype、坐标、单位及缺失项；不把数值场箭头解释为标定力。
2. 记录逻辑侧、设备serial、可获得的fid、源/接收时间、算法/SDK版本、基准及valid/stale状态；未知保持未知，不补造同帧或硬同步。
3. 已知方向的无接触、法向按压、切向移动、局部按压、扭转和释放场景，应能对照原始图、数值场和wrench，记录漂移及迟滞。
4. 网络预处理使用固定统计/尺度，保留正负和绝对幅值，不逐帧min-max。向量翻转增强须同步调整分量符号。
5. 录制报告覆盖期望/实际topic差异、频率、年龄分位、丢帧/乱序、数组有效性和字段配对；看板和机器输入须能追溯到相同来源。
6. 对同一已录样本比较在线与离线的最终Tensor；缺失、无效、身份变化和时钟回退行为应有明确理由与契约。
7. 标定精度、时间同步与长期吞吐分别验收；短测、内部残差和显示正常不能互相替代。

当前periodic的latest/时序诊断策略不等于已经满足上述源新鲜度和因果时序目标。本页不改变运行门槛或默认字段。验收时保留bag、机器可读报告、固定样本、截图、标定/版本信息和异常说明。
