# OMI HIL RL 跨领域架构

仿真阶段的数据路径：策略提出七维归一化关节增量 → 脚本或键盘接管 → 环境按关节限位生成目标 → MuJoCo 执行 → 记录原始策略动作、人工动作、最终命令动作、来源、奖励和下一观测 → 在线/示范双流回放与 SAC 更新。目标到达由 TCP 距离判定。键盘录制可在训练前导入示范流；脚本教师仍可在训练时概率接管。训练快照按固定种子独立评估，策略改善和失败对照见 [四项审计](../hil_rl_reproduction.md)。

真实设备预期沿用动作来源和单位契约，但需要独立的设备状态、时间戳、相机同步、控制延迟和现场限位。当前 `TianjiSdkArm` 仅是设备边界；没有把它接入在线 Gym actor，也没有连接 LeRobot 分布式 actor/learner。LeRobot 是计划复用的训练基础，不是当前运行栈。原始 [参考项目调查](../../../hil_serl_projects/docs/README.md) 提供背景，当前模块契约以 [接口文档](../agent/interfaces/README.md) 为准。
