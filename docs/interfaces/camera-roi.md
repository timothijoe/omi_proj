# 双相机ROI约定

策略每路输出128×128 RGB。当前固定ROI参数为外部中心比例(0.507,0.426)、短边比例0.40；腕部中心比例(0.500,0.704)、短边比例0.36。参数、裁剪边界、插值和相机mask必须与数据/模型契约一致。

旧EEF v1及七关节BC不使用腕部；v2及历史模型具有off/optional/required来源配置，不能在加载checkpoint时静默改变来源。缺失/关闭腕部采用零输入与mask0，不冒充有效黑图。

看板的外部最近邻、腕部Lanczos属于显示选择，不代表训练统一插值；EEF/grid策略预处理以 [eef_bc_grid.py](../../src/omi_hil_rl/training/eef_bc_grid.py) 和保存的base_contract为准。CameraInfo用于标定/几何，并不意味着每个网络都消费内参。

ROI改变会改变数据分布；仅显示正确不能证明在线与离线输入一致。使用前检查训练和推理处理同一样本后的数值。
